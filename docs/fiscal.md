# Estratégia Fiscal para Doações — CUBE Baby Unleashed

## Resumo

O **CUBE Baby Unleashed** é um projeto **independente, gratuito e de código aberto (GPL-3.0)**. As doações são **voluntárias**, sem troca de bens ou serviços.

---

## Situação Atual (Volume Modesto)

### Como receber

| Método | Como funciona | Fiscal |
|---|---|---|
| **Pix (CPF)** | Chave CPF, e-mail ou telefone | Doação entre PF → **não tributada** |
| **GitHub Sponsors** | Plataforma oficial | Relatório anual para IR |
| **Ko-fi / Buy Me a Coffee** | Plataforma informal | Declarar como rendimento |
| **Cripto** | Endereço de carteira | Declarar ganho de capital se houver valorização |

### Como declarar

- **Doações PF→PF**: não são renda tributável. Guarde os comprovantes.
- **Se a plataforma classificar como "rendimento"**: declare como "rendimentos não tributáveis" (doações) ou "rendimentos tributáveis" se for o caso.
- **Cripto**: se valorizou desde a doação, há ganho de capital. Declare no IR.

---

## Quando Crescer (Volume Alto)

### Limite prático

Se as doações ultrapassarem **~R$ 2–3 mil/mês**, é hora de abrir um **CNPJ**.

### Opções de CNPJ

| Tipo | Indicado para | Complexidade |
|---|---|---|
| **EIRELI** | Empreendedor individual | Baixa |
| **Sociedade Simples** | Profissionais liberais | Média |
| **Microempresa (ME)** | Pequeno negócio | Média |

### Vantagens do CNPJ

- Receber formalmente de empresas (patrocínios)
- Emitir recibos de doação
- Separar patrimônio pessoal do projeto
- Conta bancária jurídica

### Custos

- Contador: ~R$ 200–400/mês
- Conta jurídica: ~R$ 50–100/mês
- Impostos: DAS (~R$ 70/mês para Simples Nacional)

---

## O que NÃO fazer

- ❌ Receber recorrente em CPF como se fosse venda de software (é sonegação)
- ❌ Cobrar "taxa de doação obrigatória" (isso é venda, não doação)
- ❌ Receber de patrocinador enterprise sem nota fiscal
- ❌ Usar marca M-VAVE/CUVAVE/Sinco sem autorização

---

## Recomendação

1. **Agora**: GitHub Sponsors + Pix (CPF). Simples, sem custo, sem problema fiscal.
2. **Se ultrapassar ~R$ 2–3 mil/mês**: abra um **EIRELI** ou **Sociedade Simples**.
3. **Se quiser aceitar de empresas**: CNPJ é obrigatório.

## Aviso Legal na Interface

O programa mostra na aba "Apoiar o projeto":
